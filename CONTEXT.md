# URL shortener

A visitor turns a Target URL into a Short link. Following that Short link is a Redirect to the Target URL.

## Language

**Visitor**:
A person who uses the service without an identity.
_Avoid_: user, customer, client

**Target URL**:
The URL a visitor wants people to reach.
_Avoid_: long URL, original URL, destination, destination URL

**Short link**:
The compact URL a visitor receives and shares.
_Avoid_: short URL, tiny URL, shortened URL

**Short code**:
The opaque identifier inside a Short link that selects one mapping.
_Avoid_: slug, hash, id, key, path

**Redirect**:
The resolution of a Short link to its Target URL.
_Avoid_: navigation, route, SPA route, page
